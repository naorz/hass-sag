# Android Certificate Installation

Android doesn't support automated certificate installation from CLI. The process is manual but straightforward.

## Step 1: Transfer the Certificate

Get `device-cert.p12` onto your device:
- **Download** from the distribution portal (`setup.yourdomain.com`)
- **Google Drive**: Upload and open from Drive app
- **USB**: Connect phone and copy the file
- **QR Code**: Scan the QR code generated by the tool to open the portal

## Step 2: Install the Certificate

The exact path varies by Android version and manufacturer:

### Android 11+
1. Go to **Settings > Security > More security settings > Encryption & credentials**
2. Tap **Install a certificate**
3. Choose **VPN and app user certificate**
4. Select the `.p12` file
5. Leave password empty (or enter if you set one)
6. Give it a name (e.g., "Home Assistant")

### Samsung (One UI)
1. **Settings > Biometrics and security > Other security settings**
2. **Install from device storage**
3. Select the `.p12` file

### Pixel / Stock Android
1. **Settings > Security > Encryption & credentials**
2. **Install a certificate > VPN & app user certificate**
3. Select the `.p12` file

## Step 3: Verify

1. Open Chrome
2. Navigate to `https://ha.yourdomain.com`
3. Chrome should prompt for the certificate on first visit
4. Select your certificate — subsequent visits are automatic

## Troubleshooting

- **"No certificates found"**: Make sure you're installing as "VPN and app user certificate", not "CA certificate"
- **Home Assistant app**: The HA app on Android uses the system certificate store, so once installed, it works automatically
- **Certificate prompt every time**: This is normal on some Android versions. Chrome should remember the choice per domain
